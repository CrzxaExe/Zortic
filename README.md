## Features

### Notes
 
Just like other notes app, there is CRUD method, sorting logic, collection(folder), import and export into something.
UI design just so simple, it will easier other people use this app(i am just bad at UI/UX).

### Files

The Files page can browse folders using an absolute path and create, read, edit, or delete regular UTF-8 text files in the opened folder. Symbolic links and binary/non-UTF-8 files are not supported.
